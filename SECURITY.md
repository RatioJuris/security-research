# Reporting

## Report a security issue

If you have found a security issue in a public website or system and would like help reporting it responsibly, or you want to report an issue in anything published by RatioJuris, email **RatioJuris@duck.com** with:

- what you observed, and where (URLs, dates, screenshots);
- how it can be reproduced, using only publicly available access; and
- whether the affected organisation has already been informed.

Please do not include passwords, personal data or exploit code in public GitHub issues.

## Corrections

If anything in this repository is inaccurate, incomplete or unfair to the organisations discussed, please email **RatioJuris@duck.com** or open an issue. Corrections are made openly, and the full history is kept in this repository.

## Our conduct

- Research uses publicly served content and public archives only.
- No systems are accessed, tested or probed without authorisation.
- Findings are reported to the responsible organisation before publication.
