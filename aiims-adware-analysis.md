# AIIMS Delhi Website Adware Infection Analysis

## Overview

This document summarizes a security observation involving adware-related behavior identified on the official website of the All India Institute of Medical Sciences (AIIMS), New Delhi.

The issue was originally documented through an investigative article authored by Isrg Rajan.

Article reference:  
https://www.isrgrajan.com/the-official-website-of-aiims-delhi-is-infected-with-adware.html

The observation highlights how unauthorized scripts and advertisement redirects can affect the integrity of institutional web platforms.

---

## Background

AIIMS Delhi is one of India's premier public medical institutions and its official website serves as an important information portal for:

- patients
- students
- researchers
- public announcements
- healthcare services

Because of the high public trust and traffic volume, any security compromise affecting such a platform can have significant implications.

---

## Observed Behavior

The website displayed behavior consistent with adware infection or injection, including:

- unexpected advertisement redirects
- unauthorized ad scripts appearing within page content
- pop-up advertisements unrelated to the official website
- suspicious third-party script calls

These behaviors suggested that the website may have been affected by injected scripts or compromised content delivery.

---

## Possible Causes

Several scenarios could explain the observed behavior:

### 1. Third-party script injection

External scripts embedded in the website may have been compromised or modified to deliver advertising payloads.

### 2. Content management system vulnerability

If the website used a CMS platform, outdated plugins or components could allow attackers to inject malicious code.

### 3. Server-side compromise

Unauthorized access to the web server could allow modification of page templates or JavaScript files.

### 4. Advertising malware networks

Some adware campaigns inject scripts into public websites to generate traffic and revenue through forced redirects.

---

## Potential Risks

Adware infections can introduce several security concerns:

- degradation of institutional credibility
- exposure of users to malicious advertisements
- risk of malware distribution through redirect chains
- privacy risks if user data is tracked by injected scripts

In public sector websites, such issues can undermine trust and disrupt access to critical services.

---

## Investigation Approach

The analysis involved:

- reviewing website behavior during browsing sessions
- observing unexpected advertisement elements
- identifying external script sources
- documenting abnormal redirection patterns

The observations were recorded and published to highlight potential security concerns affecting public web infrastructure.

---

## Security Recommendations

Organizations operating public websites should implement the following practices:

1. Regular security audits of web infrastructure
2. Monitoring for unauthorized script injection
3. Updating CMS components and plugins
4. Implementing Content Security Policy (CSP)
5. Continuous monitoring of third-party scripts

These measures can significantly reduce the risk of adware or script injection incidents.

---

## Conclusion

The AIIMS Delhi website adware incident illustrates the importance of maintaining strong web security practices, particularly for high-profile public institutions.

Continuous monitoring, vulnerability management, and proactive security audits are essential to preserve the integrity and trustworthiness of critical digital infrastructure.
